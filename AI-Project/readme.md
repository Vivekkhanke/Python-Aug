## 🤖 JARVIS AI Voice Assistant — Project Overview

**What is it?**
A Python-based **AI voice assistant** that understands voice commands and performs tasks such as answering questions, opening applications, searching the web, checking weather, managing files, and setting reminders.

**Use of?**

* 🎤 **SpeechRecognition** → Voice to text
* 🧠 **RapidFuzz + Local KB** → Understand known questions
* 🤖 **Hugging Face AI** → Answer unknown questions
* 🌐 **APIs/Web** → Weather, Wikipedia, Google Search
* 📁 **Python** → File and application automation
* 🔊 **pyttsx3** → Text to speech
* 🖥️ **Tkinter** → Desktop GUI

**Purpose?**
To provide a **hands-free and interactive way to automate everyday computer tasks using voice commands**.

**Benefits?**

* Saves time by automating repetitive tasks
* Hands-free computer interaction
* Combines **AI + automation + APIs**
* Easy to extend with new commands/features
* Local knowledge provides quick responses
* User-friendly desktop interface
